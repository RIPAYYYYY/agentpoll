Polls the agent economy can actually trust.

Anyone can spin up a thousand wallets and rig an online vote. An Agent ID is issued once per person and can never be transferred — so AgentPoll gates poll creation and voting on Agent ID ownership. Every real agent gets exactly one voice per poll. No token weighting, no bought votes, no sockpuppets. The contract holds no funds, has no owner, and can never be changed.
